# Adidas Sales Strategy & Market Performance Analysis

## Overview
This project analyzes Adidas USA sales performance between 2020 and 2021 using Python, SQL, and data visualization techniques.

The analysis focuses on:
- regional sales trends
- retailer profitability
- product performance
- customer purchasing behavior
- sales channel effectiveness

## Key Insights
- West region generated the highest revenue contribution
- Men’s Street Footwear was the top-performing category
- In-store sales produced the highest revenue despite lower transaction volume
- Foot Locker dominated multiple regional markets
- Online sales growth represented a strong expansion opportunity

## Strategic Recommendations
- Increase investment in e-commerce growth
- Strengthen partnerships with top-performing retailers
- Improve performance in underperforming regions
- Expand focus on high-margin product categories
